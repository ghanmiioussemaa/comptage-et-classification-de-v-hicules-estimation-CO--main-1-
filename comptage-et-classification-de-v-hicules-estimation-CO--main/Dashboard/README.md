# Dashboard (Comptage Intelligent)

Mini-projet frontend React (Vite) pour reproduire le dashboard présenté.

Installation

```bash
cd "C:/Users/HP/OneDrive - SUPCOM/Bureau/Dashboard"
npm install
npm run dev
```

Notes
- L'app utilise Vite + React + Chart.js (react-chartjs-2).
- Les données sont mockées dans `src/data/mockData.js`.
- Frontend minimal: `src/App.jsx`, `src/components/*`, `src/styles.css`.
